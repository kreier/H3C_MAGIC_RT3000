Standardwerte & Erstabsicherung

  • Weboberfläche (LuCI): http://192.168.10.1/ (nur über LAN, Argon-Design).
  • SSH: ssh root@192.168.10.1 (nur über LAN, beim ersten Start ohne Root-Passwort).
  • Standard-WLAN: OpenWrt (2,4 GHz) und OpenWrt-5G (5 GHz), WPA2-Passwort 12345678, Ländercode CN.

LuCI-Sprache von Chinesisch auf Deutsch / Englisch umstellen

Öffne http://192.168.10.1/ im Browser, wechsle zu System → System → System Properties → Language and Style (系统 → 系统 → 语言和界面), stelle die Sprache auf auto (oder English) und klicke auf Save & Apply. Passe anschließend unter Network → Wireless SSIDs, Passwörter und den Ländercode an.
