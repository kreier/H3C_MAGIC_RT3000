Schritt 3: OpenWrt über die U-Boot-Rettungsseite flashen

Mit installiertem IPQ50XX-Uboot v0.2.0+ wird OpenWrt 21.02.7 (QSDK 11.5) bequem über die Argon-Rettungsseite in Slot 2 (rootfs_1) geflasht, sodass Slot 1 das originale H3C-System als Rückfallebene behält.

3.1 .ubi-Image vorbereiten & prüfen

Lade das passende HW-B-Factory-UBI aus FlyFish-go/H3C-RT3000-Product-R1 (z. B. H3C-Magic-r14-HW-B-nand-factory.ubi) herunter und prüfe die SHA-256-Prüfsumme:

mkdir -p ~/rt3000-openwrt && cd ~/rt3000-openwrt
7z x ~/Downloads/<firmware-archiv>.7z   # falls als .7z heruntergeladen
sha256sum *.ubi

3.2 U-Boot-Web-Rettungsseite starten

  1. Alle anderen Kabel abziehen (insbesondere WAN) und den PC mit genau einem Ethernet-Kabel an LAN1 verbinden. (Auf HW-B ist ethrotate=no nicht fixiert — ein angeschlossenes WAN-Kabel kann dazu führen, dass U-Boot während der Link-Aushandlung vom LAN-Port wegschaltet.)
  2. Stromkabel vom RT3000 abziehen.
  3. Die RESET-Taste gedrückt halten (auf HW-B löst nur RESET den Recovery-Modus aus; WPS/MESH dient nur zur Statusanzeige).
  4. Stromkabel bei gedrückter RESET-Taste wieder einstecken.
  5. Die rote LED blinkt im Sekundentakt: bis zum 3. roten Blinken halten, bis die LED dauerhaft grün leuchtet, dann loslassen.

3.3 http://192.168.10.1 im Browser öffnen

Der eingebaute DHCP-Server von uBootKit vergibt automatisch eine IP aus 192.168.10.100–192.168.10.200. Falls keine DHCP-Adresse zugewiesen wird, vergebe statisch 192.168.10.2 (Subnetzmaske 255.255.255.0) und öffne http://192.168.10.1 (per http://, nicht https://).

Weiße Seite mit nur einem grünen Balken oben?
Der Browser nutzt möglicherweise alte Cache-Dateien der H3C-Oberfläche (ebenfalls auf 192.168.10.1) oder bricht /main.js bei parallelen Anfragen ab. Öffne ein Inkognito-/Privat-Fenster, rufe einmal http://192.168.10.1/main.js auf und öffne danach http://192.168.10.1/.

3.4 OpenWrt in Slot 2 (rootfs_1) flashen

  1. Prüfe unter System Info: Hardware Family = HW-B, automatisch erkanntes NAND-Modell/ECC und 5-GHz-FEM (none → HW-B).
  2. Wechsle zu Firmware Update und wähle Slot 2 (rootfs_1, 0x3100000), damit Slot 1 (rootfs, 0x900000) das Originalsystem behält.
  3. Lade H3C-Magic-r14-HW-B-nand-factory.ubi hoch und warte auf den Abschluss von Schreiben und Verifikation.
  4. Gehe zurück zu System Info, klicke bei rootfs_1 (Physical slot 2) auf Set as default und starte neu.
  5. Stelle deinen Netzwerkadapter ggf. wieder auf DHCP zurück und warte ~60 Sekunden auf den ersten Start von OpenWrt.

3.5 Checkliste nach dem ersten Start

  • Sofort ein Root-Passwort per ssh root@192.168.10.1 → passwd vergeben.
  • LuCI-Sprache unter System → System → Language and Style auf auto / Englisch umstellen.
  • Standard-WLAN-SSIDs/Passwörter unter Network → Wireless ändern und das WAN-Kabel wieder anschließen.
