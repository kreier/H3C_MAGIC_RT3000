Schritt 2: IPQ50XX-Uboot v0.2.0+ installieren

Ersetze den originalen H3C-U-Boot in 0:APPSBL (mtd11) und 0:APPSBL_1 (mtd12). Lade keine .mbn-Dateien in die H3C-Weboberfläche hoch — diese akzeptiert nur signierte Herstellerpakete.

Option A: Direktes Flashen per Telnet (ohne Werks-Update)

Empfohlen, wenn Telnet (debugshell) bereits unter RT3000V100R005L01 aktiv ist.

1. Herunterladen, Prüfen & Bereitstellen auf 192.168.10.3

mkdir -p ~/rt3000-stage && cd ~/rt3000-stage
curl -LO https://github.com/FlyFish-go/IPQ50XX-Uboot/releases/download/v0.2.0/h3c-hw-b.mbn
curl -LO https://github.com/FlyFish-go/IPQ50XX-Uboot/releases/download/v0.2.0/SHA256SUMS
grep h3c-hw-b.mbn SHA256SUMS | sha256sum -c -

# Im LAN bereitstellen und fertige Flash-Befehle ausgeben:
python3 scripts/rt3000_helper.py serve ~/rt3000-stage/h3c-hw-b.mbn --local-ip 192.168.10.3 --port 8899

2. Download & Sicherheitsprüfungen auf dem Router

cd /tmp
wget http://192.168.10.3:8899/h3c-hw-b.mbn -O /tmp/appsbl.mbn
sha256sum /tmp/appsbl.mbn
ls -l /tmp/appsbl.mbn

cat /proc/mtd | grep -E "mtd11|mtd12"
# Erwartet:
# mtd11: 00140000 00020000 "0:APPSBL"
# mtd12: 00140000 00020000 "0:APPSBL_1"

cat /sys/class/mtd/mtd11/bad_blocks /sys/class/mtd/mtd12/bad_blocks
# Erwartet: 0 und 0
Wichtige Flash-Sicherheitsregeln
  • Niemals dd zum Schreiben auf NAND /dev/mtd* verwenden! Immer mtd write (oder flash_erase + nandwrite -p) nutzen.
  • Sofort abbrechen, falls SHA-256 abweicht, die Größe nicht 00140000 beträgt oder bad_blocks ungleich 0 ist.
  • Immer zuerst den inaktiven Backup-Slot (mtd12) schreiben und per Rücklese-SHA-256 prüfen, bevor der aktive Slot (mtd11) beschrieben wird.

3. Erst Backup-Slot, danach aktiven Slot schreiben

SIZE=$(wc -c < /tmp/appsbl.mbn)

# 1) Backup-Slot (mtd12 / 0:APPSBL_1) schreiben und Rücklese-SHA-256 prüfen:
mtd write /tmp/appsbl.mbn /dev/mtd12
dd if=/dev/mtd12 bs=1 count="$SIZE" 2>/dev/null | sha256sum
sha256sum /tmp/appsbl.mbn

# 2) NUR wenn beide SHA-256-Hashes zu 100% identisch sind, aktiven Slot (mtd11) schreiben:
mtd write /tmp/appsbl.mbn /dev/mtd11
dd if=/dev/mtd11 bs=1 count="$SIZE" 2>/dev/null | sha256sum
sha256sum /tmp/appsbl.mbn

# 3) Wenn BEIDE übereinstimmen, sync und Neustart:
sync && reboot

Nach dem Neustart bootet der Router über das neue U-Boot ganz normal in die originale Firmware.

Option B: BootBridge Web (Browser-geführte Installation)

Alternativ zum Telnet-Weg bietet FlyFish-go eine browsergeführte Installation:

  1. Original-Firmware zunächst über die H3C-Weboberfläche auf RT3000V100R015 aktualisieren (BootBridge prüft die exakte SHA-256 von R015).
  2. BootBridge Web öffnen, RT3000 wählen, die offizielle RT3000V100R015-Datei lokal im Browser zu einem Bridge-Image verarbeiten und dieses in der H3C-Weboberfläche einspielen.
  3. Nach dem Neustart per LAN-Kabel http://192.168.10.1 öffnen und dem Assistenten folgen (Detect → Backup → Install).
