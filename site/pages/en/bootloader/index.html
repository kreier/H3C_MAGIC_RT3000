uBootKit Origin & Architecture

Understanding where the bootloader used by FlyFish-go/IPQ50XX-Uboot comes from, what each upstream layer contributes, and where it lives on the RT3000's 128 MiB flash.

Open-Source Lineage

Layer 1 · Upstream Base

Qualcomm QSDK 12.5 u-boot-2016

Base Qualcomm IPQ U-Boot 2016.01 tree from CodeLinaro NHSS.QSDK.12.5 and 1980490718/u-boot-2016 (AU_LINUX_QSDK_NHSS.QSDK.12.5_TARGET_ALL.12.5.2783.2994), plus DHCP + web failsafe concepts from Yuzhii0718/bl-mt798x-dhcpd (a variant of hanwckf's MT798x U-Boot).

Layer 2 · uBootKit

chenxin527/uboot-qsdk12.5-build

The direct upstream uBootKit project for Qualcomm IPQ50xx / IPQ53xx / IPQ60xx / IPQ807x routers. Introduces the modern Argon-style Web rescue UI, built-in DHCP server (no manual static IP required), and unified multi-SoC build tooling.

Layer 3 · IPQ50XX-Uboot

FlyFish-go/IPQ50XX-Uboot

Adds H3C NX30/RT3000/RC3000/RW3000 board support (HW-A–HW-D), runtime SPI NAND & ECC auto-detection (v0.2.0+), vendor-compatible BOOTCONFIG dual-slot management, 80/116 MiB partition merging, pre-write safety checks, and BootBridge Web.

The full git commit history from chenxin527/uboot-qsdk12.5-build is preserved in FlyFish-go's earlier repository FlyFish-go/H3C-NX30-Uboot.

Where uBootKit Is Installed on Flash

In the Qualcomm IPQ50xx boot chain (PBL → SBL1 → QSEE/DEVCFG → APPSBL → Linux), U-Boot is the APPSBL (Applications Processor Secondary Boot Loader) stage. On the RT3000, it occupies two mirrored slots (see the 128 MiB Partition Layout):

PartitionMTDAddress RangeSlot SizeuBootKit v0.2.0Stock U-Boot
0:APPSBL (Primary) mtd11 0x00500000–0x00640000 1,280 KiB (1.25 MiB) 628.2 KiB (49.1%) 415.6 KiB (32.5%)
0:APPSBL_1 (Backup) mtd12 0x00640000–0x00780000 1,280 KiB (1.25 MiB) 628.2 KiB (49.1%) 415.6 KiB (32.5%)
  • Total allocated bootloader space: 2.50 MiB (1.95% of the 128 MiB NAND chip).
  • Actual binary footprint (h3c-hw-b.mbn, 643,280 bytes × 2): 1.23 MiB (0.96% of the 128 MiB chip).
  • Environment & slot selection: U-Boot reads/writes runtime variables in 0:APPSBLENV (mtd10, 512 KiB), while 0:SBL1 picks slot 0 or 1 from 0:BOOTCONFIG / 0:BOOTCONFIG1 (mtd2/mtd3).

Why v0.2.0+ Replaces Legacy v0.1.0

One Binary per Hardware Group
Legacy H3C-NX30-Uboot v0.1.0 shipped an 84-image matrix (4 board groups × 21 NAND/ECC combinations). IPQ50XX-Uboot v0.2.0+ replaces that with a single file per board group (h3c-hw-b.mbn for RT3000 HW-B) that probes the SPI NAND chip ID and ECC strength automatically at boot.
