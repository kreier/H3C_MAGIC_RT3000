OpenWrt 21.02.7 (QSDK 11.5 with NSS)

Target firmware from FlyFish-go/H3C-RT3000-Product-R1: OpenWrt 21.02.7 built on Qualcomm QSDK 11.5 with full NSS hardware acceleration (~940 Mbps wired NAT) and the Argon LuCI web interface.

Release File Types (.ubi vs sysupgrade.bin)

File Pattern (for HW-B)Where to FlashKeeps Settings?Purpose
H3C-Magic-r14-HW-B-nand-factory.ubi U-Boot Web Rescue Page (http://192.168.10.1) No (clean slot write) First-time install into Slot 2 (rootfs_1) or clean recovery.

Check Latest Releases Automatically
Run python3 scripts/rt3000_helper.py releases --hw HW-B to fetch the latest firmware release tag, download URLs, and SHA-256 digests directly from GitHub.

First-Boot Defaults & Security Hardening

  • Web UI (LuCI): http://192.168.10.1/ (LAN only, Argon theme).
  • SSH: ssh root@192.168.10.1 (LAN only, no root password on first boot).
  • Default Wi-Fi: OpenWrt (2.4 GHz) and OpenWrt-5G (5 GHz), WPA2 password 12345678, country CN.
# Immediately set a root password over SSH:
ssh root@192.168.10.1
passwd

Switching LuCI from Chinese to English / German

Open http://192.168.10.1/ in your browser, navigate to System → System → System Properties → Language and Style (系统 → 系统 → 语言和界面), set Language to auto (or English), and click Save & Apply. Then update your Wi-Fi SSIDs, passwords, and regulatory country code under Network → Wireless.
