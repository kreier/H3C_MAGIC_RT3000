Optional Merged Partition Layouts

The default 40 + 40 MiB layout preserves your stock H3C firmware in Slot 1 while OpenWrt runs in Slot 2. If you need space for heavy packages (e.g., OpenClash, PassWall, Tailscale, Docker), the uBootKit Web Rescue page offers two optional single-slot layouts defined in u-boot-2016/lib/rt3000_b_layout.c:

  • Merged 80 MiB (83,886,080 B / 62.50%): Combines rootfs + rootfs_1 while leaving vendor partitions untouched.
  • Max 116 MiB (121,634,816 B / 90.63%): Reclaims rootfs, rootfs_1, pdt_data, pdt_data_1, exp, and plugin into a single 116 MiB UBI volume while keeping the first 9 MiB boot/ART area intact.
