Original Stock Firmware (QSDK 4.4 / Chaos Calmer)

Before migrating to OpenWrt 21.02.7, the China Telecom H3C Magic RT3000 ships with stock firmware RT3000V100R005L01 — built on OpenWrt Chaos Calmer 15.05 (2015) and Qualcomm QSDK 4.4 (Linux 4.4.60).

Stock Web Interface

The factory H3C admin interface defaults to Basic Mode (简化版). Switching to Pro Mode (专业版) unlocks configuration backup/restore for enabling Telnet:
