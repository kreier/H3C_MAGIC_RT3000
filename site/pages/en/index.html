H3C Magic RT3000 (HW-B) — OpenWrt 21.02.7 Guide

Complete documentation for migrating the China Telecom H3C Magic RT3000 (HW-B) from its 11-year-old stock Chaos Calmer 15.05 firmware to OpenWrt 21.02.7 (QSDK 11.5 with NSS hardware acceleration) using IPQ50XX-Uboot v0.2.0+, while keeping the factory dual-boot fallback intact.

Documentation Overview

Instead of cramming every hardware detail, partition table, and shell command onto a single page, the project is organized into focused sections:

Hardware & Variants

Identify HW-A/B/C/D via 0:CDT and 0:ART, inspect NAND/ECC parameters, and avoid bricking.

128 MiB Partition Layout

Interactive hoverable flash diagram, 9 MiB boot zoom, layout switcher (40+40 / 80 / 116 MiB), and all 21 MTD partitions.

uBootKit Origin & Slot

Open-source lineage from QSDK 12.5 and chenxin527/uBootKit to IPQ50XX-Uboot, plus APPSBL slot usage.

Step-by-Step Installation

Activate Telnet, dump full MTD backups, flash U-Boot safely across both APPSBL slots, and install OpenWrt in Slot 2.

Dual-Boot & Upgrades

Interactive LED timing guide to switch between Stock and OpenWrt without a PC, plus routine LuCI upgrades.

Python Helper Script

Automate read-only probing, offline backup inspection, MTD streaming backups, and local HTTP serving with rt3000_helper.py.

Upstream Repositories

  • OpenWrt 21.02.7 / QSDK 11.5 firmware: FlyFish-go/H3C-RT3000-Product-R1
  • U-Boot (recommended, v0.2.0+ — auto-detects NAND & ECC): FlyFish-go/IPQ50XX-Uboot (Official Docs)
  • Legacy U-Boot (v0.1.0, superseded): FlyFish-go/H3C-NX30-Uboot — not needed for new installs.
  • Upstream uBootKit: chenxin527/uboot-qsdk12.5-build

Reference Network Setup

  • Router (H3C Magic RT3000): 192.168.10.1 — connect your PC via Ethernet to a LAN port (both U-Boot rescue and OpenWrt LuCI bind to LAN).
  • Linux helper machine: 192.168.10.3 on the same LAN (192.168.10.0/24).
  • Automation tool: scripts/rt3000_helper.py (pure Python 3 stdlib, zero pip dependencies).
