Step 3: Flash OpenWrt via U-Boot Web Rescue

With IPQ50XX-Uboot v0.2.0+ installed, flash OpenWrt 21.02.7 (QSDK 11.5) into Slot 2 (rootfs_1) via the Argon Web Rescue interface so Slot 1 keeps your stock H3C system as a safe fallback.

3.1 Prepare & Verify the .ubi Image

Download the latest HW-B factory UBI image from FlyFish-go/H3C-RT3000-Product-R1 (e.g., H3C-Magic-r14-HW-B-nand-factory.ubi) and verify its SHA-256 checksum:

mkdir -p ~/rt3000-openwrt && cd ~/rt3000-openwrt
7z x ~/Downloads/<your-firmware-archive>.7z   # if downloaded as .7z
sha256sum *.ubi

3.2 Enter the U-Boot Web Rescue Page

  1. Unplug all other cables (especially WAN) and connect a single Ethernet cable between your PC and LAN1. (On HW-B, ethrotate=no is not pinned, so having WAN plugged in can cause U-Boot to rotate away from LAN during link negotiation.)
  2. Unplug power from the RT3000.
  3. Hold down the RESET button (on HW-B, only RESET triggers recovery; WPS/MESH is status-only).
  4. Plug power back in while holding RESET.
  5. Watch the red LED blink once per second: hold through the 3rd red flash until the LED turns solid green, then release RESET.

3.3 Open http://192.168.10.1

uBootKit's built-in DHCP server assigns your PC an address in 192.168.10.100–192.168.10.200. If DHCP does not assign one, set a static IP of 192.168.10.2 (netmask 255.255.255.0) and open http://192.168.10.1 (plain HTTP, not HTTPS).

Blank White Page with Only a Green/Teal Top Bar?
Your browser may be reusing cached files from the old H3C UI (also at 192.168.10.1) or stalling /main.js over parallel requests. Open an Incognito / InPrivate window, load http://192.168.10.1/main.js once, and then open http://192.168.10.1/.

3.4 Flash OpenWrt into Slot 2 (rootfs_1)

  1. Open System Info and confirm Hardware Family = HW-B, detected NAND model/ECC, and 5 GHz FEM (none → HW-B).
  2. Go to Firmware Update and select Slot 2 (rootfs_1, 0x3100000) so Slot 1 (rootfs, 0x900000) preserves stock firmware.
  3. Upload H3C-Magic-r14-HW-B-nand-factory.ubi and wait for write + verification to finish.
  4. Return to System Info, click Set as default under rootfs_1 (Physical slot 2), and reboot.
  5. Switch your PC Ethernet adapter back to DHCP (if you set a static IP) and wait ~60 seconds for OpenWrt to boot.

3.5 First Boot Checklist

  • Set a root password immediately via ssh root@192.168.10.1 → passwd.
  • Switch LuCI language from Chinese to English under System → System → Language and Style.
  • Change default Wi-Fi SSIDs/passwords under Network → Wireless and reconnect your upstream WAN cable.
