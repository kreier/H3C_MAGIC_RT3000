Step 1: Activate Telnet & Back Up MTD Partitions

Before modifying U-Boot or flashing OpenWrt, unlock debugshell via Telnet on the stock H3C firmware and create a verified backup of mtd0–mtd15 (preserving your unit's unique 0:ART Wi-Fi calibration and MACs).

1.1 Enable Telnet via RT3000.cfg

  1. Log into the stock H3C web UI (http://192.168.10.1) and switch from 简化版 (Basic Mode) to 专业版 (Pro Mode) at the bottom.
  2. In the left menu, click 设备管理 (Device Management) → 配置管理 (Configuration Management).
  3. Click 备份 (Backup) to download the plaintext RT3000.cfg.
  4. Edit line 31 so telnetenable is set to enable:
@telnet
#
	telnetenable=enable
  1. Upload the edited RT3000.cfg under 恢复 (Restore) and wait for the router to apply it.
  2. Connect via Telnet and enter BusyBox root ash with debugshell:
telnet 192.168.10.1 23
# At the <H3C_RT3000> prompt:
debugshell

1.2 Automated Full Backup (Recommended)

From your Linux machine (192.168.10.3 on the same LAN), stream mtd0–mtd15 directly over TCP and verify every partition's exact byte size and MD5 checksum:

python3 scripts/rt3000_helper.py backup --host 192.168.10.1 --local-ip 192.168.10.3 --out ./backup_rt3000 --7z
Keep Your Backup Private & Safe
Your backup archive contains your router's unique Wi-Fi calibration data (0:ART), MAC addresses, and serial number. Never publish it publicly, and keep a copy before touching flash.

1.3 Manual Streaming Backup via dd + nc

Because mtd15 (rootfs) is 40 MiB and too large for the router's RAM /tmp, stream it directly to 192.168.10.3:

# On Linux host (192.168.10.3):
nc -l -p 9000 > mtd15_rootfs.bin

# On router debugshell (192.168.10.1):
dd if=/dev/mtd15 bs=4096 | nc 192.168.10.3 9000
dd if=/dev/mtd15 bs=4096 | md5sum

Confirm mtd15_rootfs.bin is exactly 41,943,040 bytes (40 MiB) and matches the router's md5sum. Repeat for mtd0–mtd14 (especially 0:SBL1, 0:MIBIB, 0:BOOTCONFIG*, 0:CDT, 0:APPSBLENV, 0:APPSBL*, and 0:ART).
