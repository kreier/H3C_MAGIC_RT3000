Step 2: Install IPQ50XX-Uboot v0.2.0+

Replace the stock H3C U-Boot in 0:APPSBL (mtd11) and 0:APPSBL_1 (mtd12). Do not upload .mbn files to the stock H3C firmware upgrade page — it only accepts signed vendor packages.

Option A: Direct Flash via Telnet (No Stock Upgrade Needed)

Use this method when Telnet (debugshell) is already enabled on RT3000V100R005L01.

1. Download, Verify & Serve on 192.168.10.3

mkdir -p ~/rt3000-stage && cd ~/rt3000-stage
curl -LO https://github.com/FlyFish-go/IPQ50XX-Uboot/releases/download/v0.2.0/h3c-hw-b.mbn
curl -LO https://github.com/FlyFish-go/IPQ50XX-Uboot/releases/download/v0.2.0/SHA256SUMS
grep h3c-hw-b.mbn SHA256SUMS | sha256sum -c -

# Serve over LAN and print copy-paste flash commands:
python3 scripts/rt3000_helper.py serve ~/rt3000-stage/h3c-hw-b.mbn --local-ip 192.168.10.3 --port 8899

2. Download & Pre-Flash Safety Checks on Router

cd /tmp
wget http://192.168.10.3:8899/h3c-hw-b.mbn -O /tmp/appsbl.mbn
sha256sum /tmp/appsbl.mbn
ls -l /tmp/appsbl.mbn

cat /proc/mtd | grep -E "mtd11|mtd12"
# Expected:
# mtd11: 00140000 00020000 "0:APPSBL"
# mtd12: 00140000 00020000 "0:APPSBL_1"

cat /sys/class/mtd/mtd11/bad_blocks /sys/class/mtd/mtd12/bad_blocks
# Expected: 0 and 0
Critical Flash Safety Rules
  • Never use dd to write to NAND /dev/mtd*! Always use mtd write (or flash_erase + nandwrite -p).
  • Stop immediately if SHA-256 differs, partition sizes are not 00140000, or either slot has non-zero bad_blocks.
  • Always flash the inactive/backup slot (mtd12) first and verify readback SHA-256 before touching the active slot (mtd11).

3. Write Backup Slot First, Then Active Slot

SIZE=$(wc -c < /tmp/appsbl.mbn)

# 1) Write backup copy (mtd12 / 0:APPSBL_1) and verify readback:
mtd write /tmp/appsbl.mbn /dev/mtd12
dd if=/dev/mtd12 bs=1 count="$SIZE" 2>/dev/null | sha256sum
sha256sum /tmp/appsbl.mbn

# 2) ONLY if both SHA-256 hashes match 100%, write active copy (mtd11 / 0:APPSBL):
mtd write /tmp/appsbl.mbn /dev/mtd11
dd if=/dev/mtd11 bs=1 count="$SIZE" 2>/dev/null | sha256sum
sha256sum /tmp/appsbl.mbn

# 3) If BOTH match, sync and reboot:
sync && reboot

After rebooting, the router boots back into stock firmware normally via the new U-Boot.

Option B: BootBridge Web (Browser-Guided Installer)

If you prefer FlyFish-go's official browser-guided workflow:

  1. Upgrade stock firmware to RT3000V100R015 via the H3C stock web UI (BootBridge validates the exact SHA-256 of R015).
  2. Open BootBridge Web, select RT3000, feed it the official RT3000V100R015 file to generate a bridge image locally in your browser, and upload that bridge image in the H3C stock web UI.
  3. After reboot, open http://192.168.10.1 over a LAN cable and follow the wizard (Detect → Backup → Install).
