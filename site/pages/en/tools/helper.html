Helper Script (scripts/rt3000_helper.py)

A pure Python 3 standard-library automation script (zero pip dependencies) designed to run on a Linux host on the same LAN (192.168.10.3) to eliminate manual errors during probing, backing up, and serving firmware images.

Read-Only by Design
rt3000_helper.py never writes to flash automatically over Telnet. For flashing, it computes and prints exact copy-paste commands with verified SHA-256 digests so you can confirm every check before erasing 0:APPSBL_1 / 0:APPSBL.

Subcommands Reference

1. probe — Live Hardware & NAND Discovery

Connects over Telnet (192.168.10.1:23), enters debugshell, reads 0:CDT, 0:ART, 0:BOOTCONFIG, /proc/mtd, and sysfs ECC/OOB parameters, and prints exact recommended U-Boot & OpenWrt filenames:

python3 scripts/rt3000_helper.py probe --host 192.168.10.1 --check-latest

2. inspect-backup — Offline .7z Backup Analysis

Decodes board group (HW-A–HW-D), BOOTCONFIG slot selectors, and non-sensitive 0:APPSBLENV variables directly from an existing MTD .7z archive without connecting to the router:

python3 scripts/rt3000_helper.py inspect-backup firmware/old_firmware.7z

3. releases — Query Latest GitHub Releases

Queries GitHub for the newest OpenWrt (FlyFish-go/H3C-RT3000-Product-R1) and U-Boot (FlyFish-go/IPQ50XX-Uboot) assets filtered for your hardware group:

python3 scripts/rt3000_helper.py releases --hw HW-B

4. backup — Stream & Verify mtd0–mtd15

Opens an ephemeral TCP listener on 192.168.10.3, streams every partition from mtd0 through mtd15, verifies exact byte length and MD5 against the router, writes md5sums.txt, and optionally packs a .7z archive:

python3 scripts/rt3000_helper.py backup --host 192.168.10.1 --local-ip 192.168.10.3 --out ./backup_rt3000 --7z

5. serve — Local HTTP Firmware Staging

Extracts a .7z/.zip or stages a single file (.mbn, .ubi, sysupgrade.bin), prints SHA-256 digests and exact router commands, and serves the directory over HTTP on your LAN:

python3 scripts/rt3000_helper.py serve ~/rt3000-stage/h3c-hw-b.mbn --local-ip 192.168.10.3 --port 8899
